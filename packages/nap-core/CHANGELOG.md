## [0.2.0] - 2026-03-21

### Added

- Protocol types for NAP HTTP authentication profile
- Base64 encoding/decoding utilities
- SHA-256 hashing helpers
- URL canonicalization for challenge verification
- NIP-98 completion validation logic
- Header parsing utilities
- Custom error types for protocol errors
