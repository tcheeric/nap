# Changelog

All notable changes to this project will be documented in this file.

## [0.2.0] - 2026-03-21

### Added

- `createNapServer()` factory for server-side NAP authentication
- Challenge issuance with configurable expiry
- Retry-safe completion verification
- In-memory challenge and session stores for local testing
- Opaque session token issuance
